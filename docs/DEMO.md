# 演示视频与讲解顺序

## 可复现的界面演示

视频展示实际 Vue 页面在受控 HTTP/SSE 服务上的交互：登录、发送、来源展开、草稿、人工确认、取消、刷新恢复和工程实验页。全程显示“非真实模型回复、不连接业务数据库”，使用合成账号。安全测试文本按文字显示，不执行 HTML。

PowerShell：

```powershell
cd F:\xiaozhi-learning\xiaozhi-ui
npm ci
npx playwright install chromium
node scripts/record-demo.mjs "F:\xiaozhi-demo"
```

输出 `xiaozhi-ui-demo.webm`、六张截图和 `demo.json`。需要15179、25179两个空闲端口，脚本只启动和清理自己的测试服务。不要把录像、浏览器输出或账号信息提交 Git。

录像通过前会检查聊天、草稿、确认、取消各请求一次，以及浏览器无页面错误。清单包含步骤时间、范围和视频SHA256；时间相对页面创建，编码时长可能略有差异。

CI 在前端任务中重新录制，产物位于 `frontend-test-reports/demo`。新发布工作流将视频及清单作为独立 Release 附件上传。视频不证明真实模型质量或实际数据库事务；这些证据由后端测试和原始评测报告提供。

## 实际小智讲解顺序

按 RUNBOOK.md 启动数据库与后端；开发方式再启动Vue，打开5173，发布包打开8081。演示时使用独立合成账号，不展示密钥或已有业务资料。

1. 展示会话隔离、历史恢复和资料来源；提出就诊准备问题，展开资料并说明出处。
2. 查询演示排班、选择时段、查看草稿。说明聊天中的“确认”不能办理预约。
3. 点击独立确认按钮，核对状态与号源；取消后查看保留记录与释放结果。
4. 打开工程实验室，对同一问题比较检索方案，解释专用重排的额外耗时。
5. 展示 PORTFOLIO.md 和原始报告，说明固定题集、故障注入、模型与程序轮次的区别。
6. 启动Python评测服务，提交任务、重复提交同一键、读取结果，说明独立进程和SQLite恢复方式。

真实 Java、数据库和云模型的整段新录像尚未录制；当前视频对应界面检查，已有云模型原文和隔离库验证可单独复查。录制真实版时应保留代码提交号、问题、日志与测量时间，再发布视频。
