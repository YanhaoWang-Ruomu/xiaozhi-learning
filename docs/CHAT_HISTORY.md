# 服务端聊天历史与会话列表

## 当前存储与接口

- chat_conversations：会话编号、标题、创建时间和所属账号userId。旧owner摘要仅用于持原浏览器密钥的用户主动导入。
- chat_history_turns：每轮一条文档，保存用户消息、最终回复、完成状态和检索来源。
- chat_memory：LangChain4j有限记忆窗口；完整历史读取不会将全部消息塞回模型。
- POST /api/conversations 创建当前账号会话；GET /api/conversations?limit=20&before=... 分页列表。
- GET /api/conversations/{id}/messages?limit=20&before=... 读取完整历史，每页20轮，支持加载更早记录。
- 接口统一使用登录会话和CSRF校验，不再使用X-Conversation-Key作为日常访问凭据。详见 ACCOUNT_AUTH.md。

## 行为与边界

- 回复完成后先保存历史再发送done；断线不自动重发，后台完成后可同步找回。
- 失败或重启遗留请求标记未完成；部分token暂不持久化。
- 当前为单后端实例，处理中状态依赖实例活动请求；多实例前需共享租约。
- 浏览器按账号分别保存当前会话位置，正文从服务端读取；切换会话重新查询草稿，退出后卸载数据视图。
- 同一账号可在不同浏览器登录并读取同一服务端历史。旧浏览器密钥认领只在原站点存储仍存在时可用。
- 旧完整历史不能从有限模型记忆重建。无归属凭据的旧记录保留但不自动分配；不会自动导入旧sessionStorage正文。
