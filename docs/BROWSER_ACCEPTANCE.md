## 本轮发现并修复的启动问题

1. 登录安全配置在非 Web 离线迁移模式下仍创建 SecurityFilterChain，导致找不到 HttpSecurity。
   仅让该过滤链在 Servlet Web 应用中创建；密码编码等基础 Bean 继续可用。
2. 离线迁移完成后，排班定时线程仍让 JVM 保持运行。
   XiaozhiApplication 仅在“非 Web + 显式启用 Mongo 迁移”时，在启动/初始化完成后关闭应用上下文，释放线程与连接池。
   正常网站启动继续常驻，不改变登录权限规则。

新增 AccountSecurityConfigTest 两项，验证离线上下文启动及密码编码器、网站模式的未登录 401 和缺少 CSRF 的 403。
2026-10-06 全后端 mvn verify：79 项，0 失败、0 错误、0 跳过，BUILD SUCCESS；日志 backend-verify.log。
临时库离线迁移运行 IMPORT_EXIT=0，正常关闭连接池；CI 已增加上述两项报告门禁。
