# 六个 Agent 方向的实现与验收范围

此表描述小智演示项目中的可运行版本。完成代码接入、通过固定测试和达到默认启用标准是三件不同的事。

| 方向 | 实现 | 默认行为与边界 |
|---|---|---|
| 自适应路由 | AdaptiveAgentRouter 按原始需求与已解析选择区分直接回复、知识、预约、澄清和普通问答；记录路由原因与步骤 | 启用有界规则。准确问候省去检索与生成，预约按查询—校验—草稿—人工确认执行；症状与未识别表达保留原链路。不是通用自主规划器。 |
| 纠错式 RAG | 最多两次检索与检查；一次改写；不足、冲突和异常分别处理；新协议只选择编号，服务器复制原文 | 默认关闭。固定24题新版本已恢复与基线持平；独立挑战与历史失败一并保留，不自动推广。 |
| 专用重排序 | gte-rerank-v2 接入 RRF 候选后，保留原候选接纳规则 | 实验页可选。固定24题平均证据召回97.5%→100%，仍默认 hybrid。 |
| 多轮评测 | 六组十一轮同步/流式评测，八项真实MySQL/Mongo工作流契约，最终状态与回复检查 | 改口、缺少选择、矛盾日期、余量变化、资料指令、工具故障；持久工作流测试中另有中断恢复及权限隔离。有限规则轮次与真实模型轮次分开计数。 |
| 回答与证据核验 | 预约草稿保存结果与本轮查询交叉核对；EvidenceBoundAnswer 逐字来源验证；可选原文摘录输出 | 业务核验默认启用；知识摘录需开启 corrective.enabled 和 corrective.extractive。只证明来源，不能证明语义相关、完整或真实；任意自由生成回答仍未具备通用逐项事实证明。 |
| 官方 Agentic 对照 | 独立 1.21.0-beta31 模块，用官方 sequenceBuilder 和 @Agent 复现有界查询与核验 | 9项离线对照通过。使用官方非AI agent，无外部模型调用；不冒充 Supervisor 自主规划或真实数据库测试，不替换主流程。 |

## 验证方式

- 主项目单元、服务和真实数据库回归由 scripts/test-mysql.ps1 执行。
- scripts/test-dedicated-rerank.ps1：默认离线，加 -Live 做真实专用模型对照。
- scripts/test-corrective-rag.ps1：默认离线，加 -Live 做原固定题对照；加 -Live -Challenge 运行新的合成证据边界样本。
- examples/agentic-comparison：官方框架独立测试。
- Vue 工程实验页提供专用排序选项，前端测试验证选择本身不会触发外部请求。
- GitHub CI 新增 Agentic 矩阵任务，共6个任务；付费模型评测不在每次CI中自动调用。

## 证据核验的具体含义

对预约，生成草稿的返回内容必须匹配医院、科室、日期、场次、医生、起止时间和待确认状态；字段缺失或冲突会要求查询记录，不宣称创建成功。查询和草稿不等同于最终确认，扣号仍需要页面明确确认。

对知识，模型只决定是否充分及选择哪些编号。程序复制本轮候选原文，拒绝未知编号。兼容旧的逐字quote结果，但仍要求引文是原文子串。开启摘录模式后直接输出带来源的引文，不再调用一个自由生成模型改写事实。原文可能包含错误或恶意指令，显示为引用不等于给这些指令授权，也不意味着完成语义事实核验。

## 后续质量门槛

只有更大且未用于调参的独立问题集通过，才考虑将纠错或专用排序设为默认。尚未完成的通用规划、任意回答逐项事实核验和跨进程模型Agent恢复，应保留为明确边界，不能以“六个方向已有实现”代替这些能力的证明。
