ZIP含Java应用、Vue资源、外部配置、MCP、Python服务、意图实验、相关源码脚本、文档与所需原始评测记录。EXTRAS.json核对模块文件，COMMIT.txt记录版本，SHA256SUMS和ZIP外部.sha256用于校验。
