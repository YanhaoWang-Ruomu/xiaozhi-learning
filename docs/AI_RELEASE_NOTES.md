# 小智导诊工作台与 Agent 实验 · v0.3.0

本版将绿色导诊工作台与六个 Agent 方向的实现一起打包。发布包内置 Vue，启动后打开 http://127.0.0.1:8081/，无需另开 5173。

## 本次变化

- 按问候、资料、预约、澄清和普通问答分流；预约采用查询、校验、草稿、人工确认的有界流程，不把聊天中的“确认”当成最终办理。
- 草稿保存结果与本轮医院、科室、日期、场次、医生、起止时间和状态交叉核对。
- 工程实验页增加 gte-rerank-v2 专用重排序；同一固定24题中，平均证据召回97.5%→100%，额外排序调用平均约1.37秒。仍默认使用 hybrid，这不是通用问答准确率。
- 纠错检索最多重查一次；模型选择编号，服务器复制原文。固定24题恢复到基线97.5%，独立12题通过11题，默认关闭。可选原文摘录只核验来源一致，不能证明内容真实、相关或完整。
- 多轮评测核对回复、工具调用及最终业务状态；保留原失败报告、实现快照和复测记录。
- 源码中新增官方 LangChain4j Agentic 独立对照工程，9项测试通过。采用非AI sequence 编排，不是自主 Supervisor，不替换主项目。

## 验证范围

实现阶段完整后端280项、前端50项、Agentic独立对照9项通过。最终真实同步和流式各6组11轮通过自动检查与逐条回答复核；每份包含10轮程序预约和1轮真实模型资料问答，不能将全部轮次当成模型规划成绩。发布要求相同提交在 main 分支的完整 CI 通过，并重新构建前端与 JAR。

实验默认值保持保守：纠错与原文摘录关闭，专用排序按需选择。真实模型评测需要外部账户和额度，不在普通启动或每次 CI 中自动执行。详细证据见 docs/AGENT_DIRECTIONS.md 及相关评测文档；独立 Agentic 工程和完整评测数据在对应源码版本中。

## 启动与版本

先启动原 MongoDB 数据目录和 MySQL84，再按 docs/RELEASE.md 启动本包。IDEA 后端与发布包默认都使用8081，切换时先停止原后端。开发模式打开5173；IDEA的 target/classes/static 可能遗留旧构建，不能据此判断发布包版本。COMMIT.txt 标明本包源码提交；推送 main 不会更新已经下载的 ZIP。

这是学习演示项目，不办理真实医疗预约。GitHub发布包不等于公网部署；公网服务器、HTTPS和Langfuse云项目仍未配置。通用自主规划、任意回答逐项事实核验及跨进程模型Agent恢复不在本版完成范围内。
