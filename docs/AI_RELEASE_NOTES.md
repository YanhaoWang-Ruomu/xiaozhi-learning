# 小智导诊工作台更新 · v0.2.1

- 更新登录、导诊聊天、会话列表、排班草稿与工程实验页；支持桌面与手机布局。
- 新增会话搜索、快捷问题填入、回复复制、阅读位置保持与回到最新消息。
- 断网时暂停发送与预约操作，联网后同步服务端结果，不自动重发。
- 新增7项Chromium检查，覆盖网络中断、刷新恢复、预约确认取消及布局；CI持续执行。
- 补齐OTLP鉴权配置，新增4项真实HTTP导出与配置校验测试。
- 按需加载前端组件与实验页，减少首次打开下载体积。

本机验证：后端122项、前端49项、浏览器7项；发布工作流要求同一提交在main分支的完整CI通过。

这是学习演示项目，不办理真实医疗预约。浏览器断网使用可控HTTP测试服务；Langfuse云项目、公网服务器与HTTPS尚未配置，GitHub发布包不等于公网网站。
详细范围与操作命令见docs/UI_ACCEPTANCE.md。
