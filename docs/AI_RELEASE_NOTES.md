# 可复现评测与 Python 任务服务 · v0.3.1

延续v0.3.0的绿色导诊工作台和Agent实现，新增评测汇总、独立Python服务及可重复录制的界面演示。启动JAR后打开 http://127.0.0.1:8081/，前端已内置；Python是可选独立模块，不改变Java预约流程。

## 本次新增

- 从原始记录计算证据召回、工具有效返回、路径耗时与失败样本，保存统计口径和来源SHA256。
- FastAPI提供任务提交、列表、状态和结果；独立进程计算报告，SQLite保存队列，支持幂等、限额、失败和重启恢复。
- Python16项检查、Linux与Windows CI，以及实际本机HTTP任务验证；固定依赖不包含机器学习训练包。
- 实际Vue页面的可复现录像：登录、SSE、资料来源、草稿人工确认、取消和刷新恢复。视频全程标明受控HTTP服务，使用合成账号。
- 补充项目展示说明、演示讲解步骤和完整README，清理过时进度与乱码段落。

## 实测结果与范围

2026-10-08记录重算：20道正例的证据召回97.5%→100%，4道无关题误接纳均0；专用重排平均额外1367.3ms。同步和流式各6组11轮通过，每份10轮为程序预约、1轮为真实模型资料问答。工具有效返回各7/8，含一次故障注入；非注入7/7。纠错边界题11/12，失败记录保留，默认关闭。

2026-10-09本机Python任务成功，重复键未重复执行；30次连续健康HTTP请求平均1.26ms、P95 1.76ms。这是单任务本机测量，不是云模型性能或并发压测。

发布要求同一提交main完整CI通过，重新构建Vue和JAR，并验证Python与录像流程。后端280项、前端50项、浏览器8项、四个框架示例5/7/12/9项和Python16项分别记录，不能相加称作真实模型正确率。

## 附件和使用

- ZIP：Java应用、外部配置、文档、只读MCP，以及可选Python服务和所需的原始评测记录。
- ZIP的SHA256：下载后核对完整性。
- `xiaozhi-ui-demo.webm` 与 `demo.json`：本次发布工作流录制的界面演示及校验清单；视频不使用真实模型或业务数据库。
- 真实模型原文、隔离数据库断言和历史失败保留在源码与评测记录中。完整实机云模型讲解视频尚未录制。

先启动原MongoDB和MySQL84，再按docs/RELEASE.md启动Java包；Python按python-eval/README.md独立启动，不需要业务库。旧的发布ZIP不会随main推送更新。

这是学习展示项目，不提供真实医疗预约；公网服务器、HTTPS与Langfuse云端仍需目标环境。机器学习实验待合适的数据与任务建立后再推进，未把无关数据集训练结果作为医疗项目成果。
