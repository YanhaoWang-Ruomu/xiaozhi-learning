# 中文请求意图分类：实验与接入安排

选择这个任务，是因为小智已经需要区分资料查询、预约需求和信息不足的追问。轻量分类模型能够学习不同表达，训练过程也能完整展示数据划分、基线比较、泛化差距和误判分析。疾病预测、诊断分类或自行训练医疗问诊模型不加入本轮。

## 本轮已实现

独立模块 [ml-intent](../ml-intent/README.md) 包含180条合成语句、36个语义/改写分组、固定训练/验证/测试划分、TF-IDF、逻辑回归、朴素贝叶斯、关键词与多数类基线。运行一次生成模型、逐条预测、分类指标、学习曲线、混淆矩阵及独立HTML报告。

18项检查覆盖数据泄漏拒绝、训练词表隔离、验证集参数选择、指标计数、模型重载、回退及禁止业务授权。依赖在独立Python环境安装；不增加主后端启动依赖。

[2026-10-09完整报告](../evals/ml-intent/20261009/REPORT.md)与[原始指标](../evals/ml-intent/20261009/metrics.json)保留实际结果。本次所选模型宏F1=0.520，关键词基线0.897；测试误判14/30。训练宏F1=1.000而验证只有0.476，暴露了表达覆盖不足与泛化差距。未校准分数阈值下，测试接受覆盖0/30，不能作为有效的在线分类器。

关键词为面向演示范围单独编写的基线，没有复现Java路由的会话状态和业务条件，也不是经过隐藏外部测试的性能结论。六条复合/范围外挑战仅留档，不算外部准确率。

## 效果如何展示

| 形式 | 展示内容 | 可检查的证据 |
|---|---|---|
| 独立HTML实验报告 | 四方案同题对照、训练/验证差距、混淆矩阵、误判与回退 | 从原始预测重算指标，展示失败而非只展示训练满分 |
| 命令行分类演示 | 输入同一句话，看意图提示、未校准分数、回退原因 | 输出advisory_only=true、action_authorized=false |
| CI可复现报告 | Linux与Windows重新安装、训练、测试、保存结果 | 依赖版本、样本哈希、测试报告、机器环境和实测耗时 |
| 后续工程实验室对照页 | 原路由与模型提示并列，核对业务实际采用的路径 | 仅影子观察，模型不决定预约创建或取消；尚未接入 |

宏F1用于平衡观察六类表现；各类精确率、召回率和支持数同时保留。CPU延迟来自单条、预热后的顺序调用，不等同于网络端到端或Qwen耗时。

## 下一步接入条件

1. 先扩展语义分组，独立复核标签；澄清类尤其需要明确“当前消息没有历史”的前提。补否定、混合意图、多轮改口和范围外请求。
2. 冻结新的独立测试集；按分组重复划分报告均值与波动。只用训练/验证调整特征、模型和阈值，旧失败题进入回归，不能继续冒充未见题。
3. 对“不检索也能回答”和“需要查资料”分别测错误成本与接受覆盖；需要可信概率时再做独立校准，当前分数不作概率解释。
4. 有稳定收益后，增加Python预测接口和Java超时回退，先在工程实验室观察；正式业务继续由医疗提示词、BookingTurn、权限、状态核验和独立确认控制。
5. 影子比较通过后再决定是否启用。若没有优于现有规则，保留实验报告和规则实现。

## 三个学习方向的推进

| 方向 | 已完成 | 下一验收 |
|---|---|---|
| 代表项目与实际评测 | 发布包、可重算指标、原始失败样本、受控界面录像 | 独立合成账号/演示数据上的真实Java+Qwen整段录像；重复云模型测量 |
| Python服务开发 | FastAPI、异步评测进程、SQLite任务、幂等与恢复 | 维护现有验证；分类接口待模型验收后再增加 |
| 完整机器学习实验 | 相关任务、合成数据、训练/验证/测试、基线、学习曲线、错误与耗时分析 | 独立人工复核与开放表达、重复分组评估；当前不替换主路由 |

这三项互相补充：Java负责可靠业务，Python承担服务和实验，评测报告解释采用或保留哪种方案。
